# Guia de Pruebas Unitarias · Backend

Para ejecutar la suite de pruebas unitarias en el backend de demostracion:

```bash
cd demo-backend
./mvnw test-compile
```

## Cobertura de Pruebas
- Validadores de formato de identificacion, correos y telefonos.
- Reglas de escala de notas y limites de creditos.
- Algoritmos de scoring multidimensional y deteccion de tendencias.
- Verificacion de constantes y sedes oficiales de la UCC.
