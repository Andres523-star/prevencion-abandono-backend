# Politica Institucional de Permanencia y Retencion · UCC

El modelo de retencion estudiantil se fundamenta en cuatro ejes estrategicos:
1. **Deteccion Temprana**: Identificacion proactiva de senales de alerta antes de la mitad del semestre.
2. **Acompanamiento Multidisciplinar**: Enlace entre tutores academicos, bienestar universitario y coordinadores.
3. **Planes de Accion Individualizados**: Recomendaciones pedagogicas asistidas por IA.
4. **Trazabilidad Institucional**: Visibilidad para decanos y vicerrectoria en tiempo real.
